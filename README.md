# 온기산후

출산한 산모가 자기 몸의 회복 속도에 맞춰 운동할 수 있게 돕는 모바일 웹앱(PWA)입니다.
분만 방식, 산후 주차, 증상을 바탕으로 오늘 해도 되는 운동만 골라 보여주고, 궁금한 것은 AI 코치에게 바로 물어볼 수 있습니다.

이 문서는 처음 보는 사람이 무엇을 만들었고, 어떻게 실행하며, 지금 어디까지 됐는지 알 수 있도록 쓴 것입니다.
디자인을 왜 이렇게 정했는지는 [docs/DESIGN.md](docs/DESIGN.md)에 있습니다.
보안 3회 점검·수정·검증은 [docs/SECURITY-REVIEW.md](docs/SECURITY-REVIEW.md), 화면별 확인 결과와 캡처 9장은 [docs/UX-REVIEW.md](docs/UX-REVIEW.md)에 남겼습니다.

## 실행하기

Node.js 20.9 이상이 필요합니다. (개발은 24.15에서 했습니다.)

```bash
npm install
npm run dev
```

- 컴퓨터: http://localhost:3000 을 엽니다. 창을 넓히면 휴대폰 모양 틀 안에 앱이 보이고, 좁히면 전체 화면으로 바뀝니다.
- 휴대폰(안드로이드, 아이폰): 컴퓨터와 같은 Wi-Fi에 연결한 뒤 `http://<컴퓨터 IP>:3000` 을 엽니다.
  컴퓨터 IP는 macOS에서 `ipconfig getifaddr en0` 으로 확인합니다.
  `.env.local`의 `DEV_ALLOWED_ORIGINS`에 실제 컴퓨터 IP만 추가하고 개발 서버를 다시 시작합니다. 전체 IP 대역 wildcard는 사용하지 않습니다.
  브라우저 메뉴의 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있습니다.

### iOS 시뮬레이터에서 앱처럼 실행

Xcode가 있는 Mac에서, 개발 서버(`npm run dev`)를 켠 채로 실행합니다.

```bash
ios/build-and-run.sh            # 이미 켜져 있는 시뮬레이터에 설치·실행
ios/build-and-run.sh "iPhone 17"  # 기기를 지정할 때
```

`ios/`는 웹앱을 전체 화면으로 띄우는 아주 얇은 앱 껍데기(WebView 하나)입니다. 주소창 없이 열리고 홈 화면에 "온기산후" 아이콘이 생깁니다.
화면과 기능은 모두 웹앱 그대로이며, 개발 서버 주소(`http://localhost:3000`)는 `ios/Info.plist`의 `AppURL`에 있습니다.
특정 화면을 바로 열어 확인하려면 실행 인자를 씁니다.

```bash
xcrun simctl launch booted com.ongi.sanhu -AppURL http://localhost:3000/today -SeedDemo 1
```

`-SeedDemo 1`은 데모 프로필(산후 7주, 제왕절개, 허리 통증)을 저장소에 넣고 시작합니다. 개발 확인용입니다.
이 껍데기는 시뮬레이터 전용입니다. 실제 아이폰에 설치하려면 Apple 개발자 서명이 필요합니다.
실제 아이폰에서는 Safari로 열고 "홈 화면에 추가"를 하면 같은 모습으로 쓸 수 있습니다.

### AI 기능 켜기

AI 코치와 "오늘 컨디션에 맞게 조정"은 Anthropic API 키가 있어야 동작합니다. 키가 없어도 나머지는 모두 동작합니다.

```bash
cp .env.example .env.local
# .env.local 을 열어 ANTHROPIC_API_KEY= 뒤에 키를 넣고 개발 서버를 다시 시작합니다.
```

키는 `.env.local`에만 두고 코드, 문서, 채팅에 붙여 넣지 않습니다. 이 파일은 Git에 올라가지 않습니다.
파일 권한은 `600`이며 AI 연결 모듈은 `server-only`로 브라우저 코드에서 가져오지 못하게 했습니다.
`node scripts/check-secrets.mjs --history`로 소스·빌드 결과·Git 이력에 현재 키가 들어갔는지 값 출력 없이 검사할 수 있습니다.
배포할 때도 키는 서버 환경변수에만 넣고 `NEXT_PUBLIC_` 접두사를 붙이지 않습니다.

BAZE API Gateway처럼 Anthropic 호환 게이트웨이를 쓰려면 `ANTHROPIC_BASE_URL`에 그 주소를 함께 넣습니다(예: `https://factchat-cloud.mindlogic.ai/v1/gateway/claude`).
이 경우 키는 게이트웨이 발급 키이고 사용료는 그 계정에 청구됩니다. 게이트웨이는 발급된 배포(deployment)에서만 키가 통합니다.

기본 모델은 `claude-opus-5-5`입니다. 비용을 낮추려면 `.env.local`의 `ANTHROPIC_MODEL`에
`claude-sonnet-5-5` 또는 `claude-haiku-5-5`를 넣습니다.

## 어떻게 동작하나

### 1. 설문 → 회복 단계

출산일, 분만 방식, 의료진의 운동 허가 여부, 불편한 곳, 위험 증상, 하루 가능 시간을 묻습니다.
이 답으로 회복 단계를 정합니다. (`src/lib/program.ts`)

| 단계 | 이름 | 조건 |
| --- | --- | --- |
| 0 | 몸 쉬어가기 | 운동 허가 전, 또는 자연분만 2주 미만 / 제왕절개 6주 미만 |
| 1 | 깊은 코어 깨우기 | 자연분만 2~6주 / 제왕절개 6~8주 |
| 2 | 버티는 힘 기르기 | 12주 미만, 또는 12주가 지났지만 복직근이개·요실금·골반 통증이 남은 경우 |
| 3 | 일상 체력 되찾기 | 12주 이후이고 위 증상이 없는 경우 |

### 2. 오늘의 루틴

운동은 전부 코드 안의 운동 목록(`src/lib/exercises.ts`, 21개)에서 나옵니다.
현재 단계보다 높은 운동, 증상에 맞지 않는 운동, 제왕절개 후 아직 이른 운동을 먼저 걸러낸 뒤,
호흡과 골반저근을 바탕으로 깔고 증상에 도움이 되는 운동부터 정한 시간 안에서 채웁니다.

### 3. AI의 역할과 한계

- **AI 코치** (`/api/chat`): 내 산후 주차와 증상을 알고 질문에 답합니다. 답은 글자가 나오는 대로 바로 보입니다.
- **AI 루틴 조정** (`/api/plan`): 오늘의 통증·피로·메모를 받아 루틴을 줄이거나 바꿉니다.

AI에게는 두 가지 선을 코드로 강제합니다.

1. AI 루틴은 위에서 걸러낸 "오늘 허용된 운동" 안에서만 고르고,
   그 밖의 운동이 돌아오면 서버가 버립니다. 세트는 기본값 이하, 횟수는 라이브러리 값으로 강제합니다.
   통증이 높거나 많이 지친 컨디션에서는 허용 운동 범주도 줄입니다. AI 조정 실패 시 기본 루틴을 유지합니다.
   자유형 코치 답변은 같은 지침을 받지만, 모든 문장을 코드로 검증하는 것은 아닙니다.
2. 위험 증상(갑자기 늘어난 출혈, 38도 이상 열, 한쪽 종아리 통증, 가슴 통증·호흡곤란, 심한 두통·시야 이상,
   상처 감염, 자신이나 아기를 해칠 것 같은 생각)은 AI에 맡기지 않고 규칙으로 먼저 찾아 진료 안내를 보여줍니다.
   (`src/lib/redflags.ts`) AI 키가 없거나 AI가 멈춰도 이 안내는 나옵니다.

### 4. 개인정보

서버 데이터베이스가 없습니다. 출산 정보, 운동 기록, 코치와의 대화는 사용자의 휴대폰 브라우저(localStorage)에만 저장됩니다. 로그인(GitHub)은 AI 코치와 루틴 조정에만 필요하고, 서버는 GitHub 숫자 번호·로그인 이름과 하루 사용 횟수만 기억합니다. 자세한 내용은 앱의 `/privacy` 화면에 있습니다.
AI 질문 또는 루틴 조정 시 분만 방식, 산후 주차, 증상과 해당 대화·컨디션 정보가 서버를 통해 설정된 AI 제공자(Anthropic 또는 호환 게이트웨이)에게 전달됩니다. 이름이나 연락처는 묻지 않습니다. 감지된 위험 증상 안내는 AI 호출 없이 처리합니다.
API 응답은 `no-store`이고, 앱은 서버 DB에 건강 정보를 저장하지 않습니다. AI 제공자의 처리·보관 정책은 별도입니다.

## 기술 구성

- Next.js 16.4 (App Router), React 19, TypeScript
- Tailwind CSS 4 (색은 `globals.css`의 토큰으로만 사용)
- `@anthropic-ai/sdk` 1.12, `zod` 4 (입력 검증, AI 응답 형식)
- `vitest` 5 (단위 테스트)

## 남은 일과 알려진 한계

1. **AI 응답 품질 검토**: 연결과 형식은 확인했지만, 답변 내용이 의학적으로 적절한지는 전문가가 봐야 합니다.
2. **전문가 감수**: 운동 내용과 단계·금기 기준은 공개된 산후 운동 가이드라인을 바탕으로 쓴 초안입니다.
   산부인과 전문의나 산후 재활 전문가의 감수 없이 실제 산모에게 배포하면 안 됩니다.
3. **위험 증상 감지는 문구 일치 방식**입니다. 다르게 표현한 문장은 놓칠 수 있습니다. AI 지침에도 같은 기준을 넣어 보완했지만 완전하지 않습니다.
4. **로그인과 사용량 제한은 붙었지만 GitHub 계정이 있는 사람만 로그인할 수 있습니다.** 산모 대상 서비스라면 카카오·구글 로그인이 필요합니다. 사용자별 하루 한도(20/5)와 전체 하루 한도(기본 500회)가 요금 상한입니다. 개발 서버에서는 로그인 없이 열려 있고, 프로덕션에서는 로그인·Redis 설정이 없으면 AI가 닫힙니다.
5. 운동 설명은 글뿐입니다. 그림이나 영상이 없습니다.
6. 기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라집니다. (로그인·동기화 없음)
7. 오프라인에서는 열리지 않습니다. (서비스 워커 없음)
8. 실제 휴대폰 기기에서의 확인은 아직 하지 않았습니다. 컴퓨터 브라우저의 휴대폰 폭으로만 확인했습니다.

## 의료 고지

이 앱은 일반적인 건강 정보를 제공하며 진단이나 치료를 대신하지 않습니다.
